# macports-highsierra
MacPorts overlay for  10.13 HighSierra

## How to Use:

Install MacPorts: <https://www.macports.org/install.php>

Retrieve repository. Run portindex in its root.

Add to sources.conf before the macports rsync, so it gets preceence.

file:///<path_to_repo_>/macports-highsierra [nosync]


Remember to run portindex everytyme you git pull new.
